Akan Name Generator
Project Description
The Akan Name Generator is a web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender. Akan names come from Ghanaian culture, where children are traditionally named based on the day they were born.
This project demonstrates key programming concepts including working with data types, using arrays, writing functions, implementing control flow and operators, and handling user input validation.
